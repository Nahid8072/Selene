# Prompt 00 — Inspect the repository; do not implement the product yet

You are working on AgentScale. Read the root `AGENTS.md` and the foundation documents before doing anything.

Task:
1. Inspect the entire repository structure and identify its current language, frameworks, tooling, existing functionality, tests and uncommitted changes.
2. Check locally available versions of Go, Git, Docker/Docker Compose and Python if those tools are present. Do not install anything.
3. Compare the current repository against `08_MILESTONES.md` and identify the exact current milestone.
4. Identify conflicts, risks, missing requirements and any existing code that should be preserved.
5. Propose a minimal folder structure and an ordered implementation plan for the next milestone only.
6. If needed, propose documentation-only changes to connect the foundation pack to the repository.

Constraints:
- Do not build the frontend.
- Do not add product features or large dependencies.
- Do not rewrite the repository or replace existing files.
- Do not run destructive commands.
- Do not commit changes.

Deliver a concise inspection report with: repository state, tooling, current architecture, risks, proposed next tasks, exact commands to run, and exit criteria. Stop and wait for review.
